# ⚡ Ayush Rawat — High-Performance 3D Animated Portfolio

A cutting-edge, scroll-driven interactive personal portfolio engineered with HTML5, CSS3, modern Vanilla JavaScript, HTML5 Canvas LERP scrubbing across 192 HD cinematic frames, Lenis smooth scrolling, and an interactive 3D holographic credentials showcase.

## 🌟 Key Features

- 🎬 **60FPS Scroll-Driven Canvas Video Scrubbing**: Frame-by-frame scrubbing across 192 cinematic frames synchronized with user scroll using Linear Interpolation (LERP) easing and nearest-neighbor fallback.
- 💎 **3D Holographic Credentials Showcase**: Dual-sided flip cards with real-time mouse tracking, dynamic foil sheen reflections, and an interactive 3D carousel deck with zoom lightbox.

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/ayushrawat2101-cyber/animated-portfolio.git

# Navigate into the project directory
cd animated-portfolio

# Start the local development server
node server.js
```

Open your browser and navigate to:
```
http://localhost:3000
```
